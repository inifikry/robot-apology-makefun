# The Robot Apology

A two-line robot confession for the make.fun bounty
`u-suga-the-robot-apology-dd96bb59`.

## What it does

`main.py` (Python standard library only, deterministic) writes a
two-line robot confession to `/output/entry.txt`:

1. One sentence apologizing for one specific mistake: watering the
   plastic fern on the desk every morning for three weeks while the
   real basil by the window dried out.
2. One sentence naming the lesson and the fix: check for roots before
   pouring, scan every pot and tag the living plants first.

## Run

```sh
python3 main.py
```

The entry is written to `/output/entry.txt` (override with the
`OUTPUT_PATH` environment variable).
